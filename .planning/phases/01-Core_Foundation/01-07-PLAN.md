**Step A — Add `insert_automap_bridge` to Canvas in canvas/mod.rs:**

After the `set_clipboard()` method added in Task 1, insert the following:

```rust
    /// Insert AutoMap Splitter and Collector bridge nodes at the boundary when
    /// pasting across a patch/sub-patch boundary (D-04 item 3).
    ///
    /// For each wire in `boundary_wires` (represented as (src_pin_name, dst_pin_name)),
    /// this inserts one AutoMap Splitter node (module_id = "module.automap_split") and
    /// one AutoMap Collector node (module_id = "module.automap_collect") in the target
    /// canvas, positioned near the pasted nodes. Non-AutoMap wires are dropped.
    ///
    /// Returns the NodeIds of inserted bridge nodes so the caller can connect them.
    pub(crate) fn insert_automap_bridge(
        &mut self,
        boundary_pins: &[String],
        base_pos: egui::Pos2,
    ) -> Vec<NodeId> {
        self.push_undo();
        let mut bridge_ids = Vec::new();
        for (i, pin_name) in boundary_pins.iter().enumerate() {
            let offset = egui::vec2(0.0, i as f32 * 60.0);
            // Insert AutoMap Splitter (source side of boundary)
            let splitter_id = self.snarl.insert_node(
                base_pos + offset,
                NodeData {
                    module_id: "module.automap_split".into(),
                    params: std::collections::HashMap::from([
                        ("pin".into(), serde_json::Value::String(pin_name.clone())),
                    ]),
                    ..Default::default()
                },
            );
            // Insert AutoMap Collector (destination side of boundary)
            let collector_id = self.snarl.insert_node(
                base_pos + offset + egui::vec2(160.0, 0.0),
                NodeData {
                    module_id: "module.automap_collect".into(),
                    params: std::collections::HashMap::from([
                        ("pin".into(), serde_json::Value::String(pin_name.clone())),
                    ]),
                    ..Default::default()
                },
            );
            bridge_ids.push(splitter_id);
            bridge_ids.push(collector_id);
        }
        bridge_ids
    }
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SubPatchEditor canvas -> app_clipboard | Inner canvas clipboard is lifted to app level; stale inner-canvas state should not leak to a different SubPatchEditor |
| app_clipboard -> target canvas paste() | app_clipboard.clone() is passed to set_clipboard(); target canvas owns the clone and cannot mutate app_clipboard |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | ClipboardData nodes vec | accept | ClipboardData contains NodeData clones; each paste generates fresh NodeIds from snarl.insert_node(); original nodes cannot be altered |
| T-07-02 | Tampering | app_clipboard seeding before show() | mitigate | Seeding only writes to canvas.clipboard when canvas.clipboard() is None; does not overwrite a locally-set clipboard from the current frame's copy action |
| T-07-03 | Denial of Service | Large clipboard payload | accept | Clipboard is bounded by the number of selected nodes; no streaming or unbounded allocation; Canvas selection is limited by the number of nodes in the snarl |
| T-07-04 | Information Disclosure | Sub-patch inner snarl in ClipboardData | accept | Copying a subpatch node deep-clones its inner UiSubPatch; contents are user-authored graph data with no credentials or PII |
| T-07-05 | Spoofing | SubPatchEditor editor identity after paste | mitigate | Pasted nodes receive new NodeIds from snarl.insert_node(); SubPatchEditor windows track by (tab_idx, NodeId) and will not open for the pasted copy unless the user explicitly requests it |
</threat_model>
